# Auditoría de referencias a IA en el código

Fecha: 2025-10-27

Resumen
- Se escaneó todo el repositorio en busca de comentarios o documentación que atribuyan la autoría del código a herramientas de IA (ChatGPT, Copilot, OpenAI, Claude, Bard/Gemini, etc.) o frases del estilo "como IA" / "generado por IA".
- No se encontraron referencias de ese tipo en código fuente o documentación versionada. Las únicas coincidencias fueron falsos positivos dentro de artefactos de build/caches (por ejemplo, cadenas "LLMV" en hashes de integridad), que no forman parte del código entregable.

Rango del análisis
- Incluye: app/src/**, functions/src/**, archivos de configuración en la raíz.
- Excluye: directorios de build y caches (.gradle, app/build, node_modules, functions/lib), que no son parte del entregable.

Patrones buscados (case-insensitive)
- Nombres de herramientas: chatgpt, gpt-3, gpt-4, openai, copilot, claude/anthropic, bard/gemini, mistral, llama, deepseek, perplexity.
- Frases de atribución: "AI language model", "LLM", "generated by", "auto-generated", "this file was generated".
- Español: "inteligencia artificial", "generado por IA", "hecho por IA", "creado por IA", "como IA", "soy una IA", "asistente de IA".

Cómo re-ejecutar el escaneo
1) Conceder permisos y ejecutar el script incluido:

```bash
chmod +x scripts/scan_ai_mentions.sh
scripts/scan_ai_mentions.sh
```

2) Si aparece alguna coincidencia, el script la imprimirá con su ruta y línea para que se pueda neutralizar el wording.

Notas
- No se añadieron ni modificaron lógicas de negocio. Solo se incorporó el script anterior para facilitar futuras verificaciones.
- Si se agregan nuevos archivos de documentación (README, etc.), conviene ejecutar el script antes de cada entrega.
